<threat_model>

## Trust Boundaries

| Boundary | Description |
|---|---|
| S3 bucket → public internet | Must be blocked; bucket policy denies all non-account principals |
| Terraform state → S3 | State contains IAM ARNs and KMS key IDs; must be encrypted at rest |
| Snowflake → S3 | Cross-account access via IAM role trust policy; ARN must be exact |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|---|---|---|---|---|
| T-01-01 | Information Disclosure | terraform.tfstate | mitigate | Remote state in S3 with encrypt=true + DynamoDB lock |
| T-01-02 | Elevation of Privilege | S3 bucket policy | mitigate | Explicit deny on all non-account principals |
| T-01-03 | Information Disclosure | KMS key | mitigate | Key policy restricts usage to account roles only |
| T-01-04 | Tampering | S3 landing objects | mitigate | Versioning enabled — deletes/overwrites are recoverable |

</threat_model>
